# CSV Org Chart Builder

A browser-only HTML tool for turning CSV org-chart data into building-based org charts.

## What it does

- Opens directly in your browser
- Requires no install
- Requires no Microsoft Visio
- Groups charts by the `Building` column
- Uses `Employee ID` and `Manager ID` to build the hierarchy
- Exports charts as SVG or PNG

## What it cannot do

A browser-only tool cannot create native `.vsdx` Visio files.

This tool creates SVG and PNG org charts instead.
