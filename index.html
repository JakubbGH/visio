Browser-only tool

CSV Org Chart Builder

Upload your CSV, generate a readable org chart split by Area, adjust the layout visually, customise styles, then export as SVG or PNG.

Editable page-fit layout
Important: A browser-only tool cannot create native .vsdx files. This creates clean .svg and .png org charts sized to fit the page.

1. Upload CSV

Layout editing and style customisation are in the left panel beside the preview. Hold Shift while clicking boxes or connectors to select multiple. Multiple uploaded CSV files are split into separate editable chart tabs by Area value. Manager and leaf rows now wrap automatically so large charts stay readable.

2. Chart

Customise selection

Click a box or connector line to customise it.

Layout editing

Turn edit mode on, then select a box or connector. Hold Shift to select multiple. Drag any selected box to move selected boxes together.

Style

Layout: drag any selected box to move the group. The green resize handle appears only on the last selected box.

Layout: selected connectors show circle handles. Drag a handle to move that connector’s elbow route.
