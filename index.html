Browser-only tool

CSV Org Chart Builder

Upload your CSV, generate a readable org chart split by Building, choose a layout style, adjust the layout visually, customise styles, export as SVG or PNG, or reimport previous SVGs.

Editable page-fit layout
Important: A browser-only tool cannot create native .vsdx files. This creates clean .svg and .png org charts sized to fit the page.

1. Upload CSV

Layout editing, layout style selection, and style customisation are in the left panel beside the preview. Hold Shift while clicking boxes or connectors to select multiple. Multiple uploaded CSV files are split into separate editable chart tabs by Building value. If a Building cell contains “/”, that person is duplicated into each listed Building chart. If a Name contains “/”, it is split into separate boxes that share links.

2. Chart

Customise selection

Click a box or connector line to customise it.

Layout editing

Turn edit mode on, then select a box or connector. Hold Shift to select multiple. Drag selected boxes or line handles; final box positions snap to rows/columns when snap is on. To add a manual line, select exactly two boxes, then click Add manual line. Select boxes and click Remove selected box(es) to hide them from the current Building chart. Use Add new box to create chart-only boxes, or Insert above selected box(es) to place a new manager between an existing reporting chain.

Edit selected box details

Select exactly one box to edit its displayed details for this Building chart. Editing Employee ID or Manager ID can change links in this chart.

Add new box

New boxes are added only to the current Building chart. Use selected box as manager adds the new person below the selected box. Insert above selected box(es) places the new person between the selected box and its current manager.

Style

Layout: drag any selected box to move the group. The green resize handle appears only on the last selected box.

Layout: selected connectors show circle handles. Drag a handle to move that connector’s elbow route.
